# C0.38 Checked Signed i64 Remainder

Implementation maturity: EXPERIMENTAL. This unnumbered design record remains
PROPOSED; no formal RFC acceptance is claimed. Fresh exact-pair and platform
qualification below is required; this is not a stable language
promise or release. Public version stays `1.0.0-alpha.1`, channel `dev`.
Full Compiler, formal self-hosting and Verified nqlc remain NOT IMPLEMENTED.

## Semantics And Precedence

`a % b` evaluates the left operand and then the right operand, exactly once.
Both are signed i64. For a nonzero divisor and a representable signed quotient,
let q be a/b truncated toward zero; the result is a-q*b. A nonzero result has
the dividend's sign and magnitude less than the divisor's magnitude.
Thus `17%5=2`, `-17%5=-2`, `17%-5=2`, `-17%-5=-2`, MIN%1=0 and MIN%MIN=0.

Executed divisor zero and INT64_MIN%-1 fault at the percent operator using the
existing located C0R-001 arithmetic diagnostic and exit70. Failed diagnostic
output retains exit74. The MIN%-1 fault is intentional: this experimental
subset shares checked signed-quotient validity with division, even though the
mathematical remainder alone would be zero. It must not reach a hardware divide
trap. No change to the existing division policy or old compiler is implied.

Constant and dynamic operands have the same runtime policy. Unselected if
branches and logical RHS do not execute a remainder fault. Name, arity, literal
and unsafe-boundary validation still checks unselected code. Only a directly
owning NEGATE node can authorize the existing magnitude2^63 literal exception;
REM grants no such permission. Unsafe scopes retain arithmetic checking.

Precedence, highest first: call/grouping; right-associative prefixes `- ~ not`;
`* / %`; `+ -`; `<< >>`; relational; equality; `&`; `^`; `|`; `and`; `or`.
Binary operators associate left: `20%6*3=6`, `20/3%4=2`, `20%6%3=2`.
Percent is one ASCII37 token; `%=` and `%%` are unsupported. Percent inside
existing line comments changes neither tokens nor selected wire version.
There are no new reserved names or implicit numeric conversions.

This is one operator in the shared Core pipeline. It supports readable Systems
Programming expressions while exposing a predictable checked x86_64 lowering
for Assembly-Level Systems Programming. Those paths are independent of the
Balanced/Safe/Unsafe modes. Balanced remains the design default; this subset
does not implement the full type, ownership or NolQu-L Safety model.

## Wire Contract And Independent Validation

Actual remainder syntax selects NQAF/11, wide32, dialect10, runtime profile0/1.
Header/records stay32 bytes with u32 spans/IDs. Kind57 REM has two nonzero,
contiguous, uniquely-owned postorder operand roots, an exact one-byte percent
anchor and zero flags/next/reserved fields. The right root immediately precedes
the parent and its subtree begins immediately after the left root.
/1..10 reject REM. /11 retains the existing unary, bitwise, logical, shift,
function, scope, literal and native permission rules; a handwritten /11 shift
graph without REM is valid. Unknown versions/dialects remain invalid.
The numeric dialect field versions the internal transport, not a second user
language or programming path.

The backend independently checks framing, bounds, source anchors, graph/
statement/function order, names/arity, literal ownership and raw-call source
containment before ELF output. This is bounded source correspondence, not
authentication of every source byte or a replacement source parser. Compile
untrusted source through the frontend. Lexical unsafe permission is not an OS
sandbox: an allowed raw syscall retains ordinary process authority.

## Machine Cost And Bounds

The checked node is68 bytes excluding operand subtrees: two7-byte
slot loads,12-byte source-prefix setup,32-byte existing checked division path,
`48 89 d0` (MOV RAX,RDX), and a7-byte result store. Its internal JNE goes from
offset30 to44; JO and JE use relative bases44 and53 and target the existing
wide arithmetic entry at file offset6291600. CQO/IDIV RCX precede the transfer
at58 and store at61. The tests below check actual generated bytes and targets.

Both operands finish before R8D/R9D receive the final operator location.
Division scratch RDX/RCX and result RAX do not overwrite that prefix or the
profile1 mapping ownership pointer. There is no new call, push/pop, helper or
runtime arena merely because REM exists. The result reuses the lowest consumed
temporary; loop back-edges inherit the complete left subtree's code-start.

Source262144, token/node65536, compiler16MiB, output8MiB, frame4096/512slots,
six arguments,64 active calls/combined scopes and the selected64KiB or16MiB
runtime arena stay unchanged. No B0 bridge, host compiler, assembler, linker or
runtime dependency is added. Node bytes are specified; no runtime speedup is
claimed. Compare compilation resource/cost on the same retained old source.

## Threat Invariants And Tests

Untrusted source crosses lexer/parser and independently supplied NQAF crosses
the verifier under ordinary privileges. Relevant failures include nonprogress,
out-of-bounds graph/span reads, silent signed/truncated wrong-code, divide traps,
lost/duplicated effects, register clobbers, unsafe-call laundering and stale
qualification. No new shell/path/privileged capability is introduced.

RM01: full64-bit signs, values and precedence match independent integer checks.
RM02: eager effects, fault order/locations, skipped paths, loop reevaluation and
failed diagnostic output preserve their specified observable behavior.
RM03: independent /11 packing and malformed framing/fields/anchors/ownership/
versions, including high u32 spans/IDs, reject before ELF output.
RM04: existing minimum-literal and native permission/range checks remain active.
RM05: unchanged source and /1..10 successful AST/ELF bytes remain identical.
RM06: deterministic B0 builds, exact suite/proof inventories and an actual named
B/C remainder oracle fail closed when missing, stale, skipped or truncated.

Permanent checks live in `tests/bootstrap/test_c0_remainder.py`, the capacity/
component-generation gate and MCP controls. Generated assertions use ordinary
`if` comparisons, not remainder or logical guards that could hide the check.
The host model uses integer truncating division, never floating conversion or
Python's signed floor-modulo convention. Deliberate wrong-result/guard variants
must fail the oracle. Fixed finite corpora and per-call watchdogs bound tests;
coverage-guided fuzz, canonical ASan/UBSan and exhaustive correctness are not
available or claimed. Python/QEMU/disassembly are host testing tools only.

## Compatibility, Qualification And Rollback

Old source retains its NQAF/1..10 selection and successful ELF bytes, including
shift-only source and percent inside comments. New /11 requires a matched
frontend/backend upgrade. CLI, ABI, library/project formats, source capacities,
trust root and Machine Foundation -> Stage0 -> B0 -> Core topology are preserved.
Both implementation sources stay in B0-supported grammar; their recognizers
use ASCII37 and existing operations, not `%` expressions in compiler source.

Require independent HIGH-risk compiler/proof review, all affected suites, actual
B/C named oracles, deterministic rebuilds, old byte parity, selected publication
validation and complete relevant Linux qualification. Fresh actual Native
component/proof receipts must show TracerPid0 before/after; PRoot or metadata
cannot substitute. Missing/skipped checks, wrong-code, unexpected nondeterminism
or unresolved correctness findings block integration. No release, tag, version
bump, Full Compiler or formal self-hosting promotion follows from this contract.

Rollback restores the complete matched C0.37 sources/seeds/pins/proof contract;
preserve originals and failed evidence. Historical C032-SIGNAL-01 remains OPEN
with unknown original cause; Native full-MCP hardlink qualification and evidence
retention retain their separately documented limits.
