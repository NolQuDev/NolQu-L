# NolQu-L Code Of Conduct

NolQu-L welcomes technical discussion, critique, and contribution, but project
collaboration should remain clear, respectful, and useful.

## Expected Behavior

- discuss ideas and code directly
- criticize technical decisions without attacking people
- keep disagreement concrete and evidence-based
- respect project boundaries, release policy, and design constraints
- prefer issues, repro cases, and patches over vague complaints

## Unacceptable Behavior

- harassment, personal attacks, or intimidation
- discriminatory or abusive language
- repeated bad-faith disruption
- impersonating official NolQu-L maintainers or channels
- using community spaces to mislead users about project status or ownership

## Project Tone

NolQu-L does not require artificial politeness, but it does require productive
conduct. Direct technical criticism is acceptable. Personal hostility is not.

## Reporting

For conduct concerns, contact:

- `nolqudev@gmail.com`
- `nolquteam@gmail.com`
- `nolqucontact@gmail.com`

## Enforcement

Project maintainers may moderate discussion, reject contributions, or remove
participation when conduct harms the project or its contributors.
