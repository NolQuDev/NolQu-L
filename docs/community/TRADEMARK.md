# NolQu-L Trademark

`NolQu-L` is the formal project and language name. Canonical commands are
`nql`/`nolqul` and `nqlc`/`nolqulc`; older spellings survive only in historical
records and do not name installed compatibility commands.

## Current Policy

- project names and branding remain reserved to the project owner unless
  explicit written permission says otherwise
- forks and third-party tools may describe compatibility with NolQu-L, but
  should not present themselves as the official NolQu-L project
- derivative distributions should avoid implying endorsement, official status,
  or trademark ownership

## Allowed Descriptive Use

The following descriptive uses are generally acceptable:

- "works with NolQu-L"
- "NolQu-L-compatible"
- "tooling for NolQu-L"

The following uses should be avoided without permission:

- naming another compiler release as the official `NolQu-L`
- using `NolQu-L`, legacy `Nolqu`, `nq`, `nqc`, or `nolquc` as if the
  trademark or brand belongs to another party
- using project branding in a way that confuses users about source or
  endorsement
