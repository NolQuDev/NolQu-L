# NolQu-L Governance

## Current Authority

The current project creator and primary authority is:

- `Nadzil`

## Current Governance Model

NolQu-L is currently maintained under a creator-led model.

That means:

- release direction is set centrally
- semantic changes should be deliberate and documented
- passing tests and explicit NolQu-L semantics remain the source of truth
- the machine foundation and staged bootstrap remain the canonical architecture
- experimental work should not silently become official language surface

## Maintainer Priorities

- preserve a simple and readable surface language
- keep implementation complexity from leaking into language design
- preserve R0 compatibility while canonical compiler stages mature
- require docs, examples, and tests for meaningful user-visible changes
